# 디자인 컨벤션

하늘색 월간 노트가 기준이다. 일정이 가장 넓게 보이게 하고, 날짜·부가 설명은 명확한 위계로 표시한다.

## 팔레트

색상은 [palette.ts](../src/components/ui/palette.ts)에서 관리한다. 컴포넌트·스타일 파일에는 HEX 색을 직접 쓰지 않는다.

| 배경 bg               | #F7FBFF   | #101E2D   |
| 본문 text             | #20344A   | #E5F2FF   |
| 보조 muted            | #566E87   | #9CB4CC   |

본문은 text, 설명은 muted, 연월·주요 행동·커서는 accent를 사용한다. 오늘의 빈 일정 칸은 selected 배경만 표시한다. 기념일 점은 accent다.

## 글꼴과 크기

Pretendard Regular·Medium·SemiBold·Bold를 앱에 번들한다. 본문·입력은 Regular 15px, 제목은 Bold 18px, 섹션 제목·확인 버튼은 Bold 15px, 작은 안내는 Regular 13px, 보조 설명은 Regular 12px를 사용한다. 줄 높이는 12px→18px, 13px→20px, 15px→22px, 18px→26px로 통일한다. 합성 굵기 대신 해당 fontFamily를 사용한다. [tokens.ts](../src/components/ui/tokens.ts)가 크기·간격의 기준이다.

| 용도                          | 토큰·크기                | 굵기                |
| ----------------------------- | ------------------------ | ------------------- |
| 화면·모달·연월 제목           | title 18px               | Bold                |
| 일정 본문                     | body 15px / 줄 높이 22px | Regular             |
| 날짜 숫자                     | date 15px                | Medium, 오늘 Bold   |
| 칩 선택 작업 버튼             | body 15px                | Bold                |
| 입력 안내·작은 버튼·시간 라벨 | small 13px               | Regular 또는 Medium |
| 요일·보조 설명                | caption 12px             | Regular             |
| 월 이동 화살표                | display 24px             | Bold                |

헤더 아이콘 터치 영역은 44px를 유지하면서 가이드·메뉴 그림을 안쪽으로 모은다. 선택 작업 버튼은 최소 높이 44px, 좌우 패딩 4px로 줄바꿈 없이 한 줄에 배치하며 선택 상태에서도 배경은 투명하다. 버튼은 내용 너비를 유지하고 작업 영역만 가로 스크롤한다. 상단 선택 개수·전체 선택 해제 영역은 좌우 8px·상하 4px 여백을 둔다. 선택 개수와 `전체선택 | 해제`는 스크롤 영역 밖에 고정하며 두 버튼은 상단 우측에 둔다. 전체선택은 현재 표시 중인 달의 일정 전체를 선택하고 해제는 선택 모드를 종료한다. 작업 버튼은 중요 일정 등록(등록 시 중요 일정 해제)·시간 설정·일정 복사·알람 설정·삭제이며 수정은 칩 한 번 탭으로 제공한다.

## 여백과 표준 모달

- 기본 간격은 4·8·12·16px다. 본문 바깥·날짜 행 여백은 4px다.
- 앱의 모든 안내·메뉴·확인 화면은 중앙에 떠 있는 Dialog를 사용한다. 바깥 여백 16px, 내부 여백 16px, 모서리 20px, 최대 너비 480px·최대 높이 85%다.
- 모든 모달은 공통 Dialog의 너비·여백·모서리·서체를 공유한다. 하단 확인 버튼은 배경 없는 accent 텍스트, Bold 15px, 최소 높이 44px, 좌우 12px·상하 8px 패딩으로 통일한다. 작업은 우측 정렬하고 삭제만 red를 사용한다.
- 제목과 본문의 시작선을 맞추고 간격은 12px로 둔다. 제목·닫기 버튼·하단 작업 영역은 고정하고 본문만 스크롤한다.
- 메뉴는 제목·닫기 버튼을 숨긴다. 항목 높이는 48px 이상, 항목 간격 8px, 좌우 패딩 16px·상하 패딩 12px다. 바깥 탭과 Android 뒤로 가기로 닫는다.
- 삭제는 표준 모달에서 “삭제하시겠습니까?”와 선택 개수를 보여준다. 본문은 Pretendard Regular 15px·text, 버튼은 배경 없이 취소 accent·삭제 red 글자와 Bold 15px를 사용한다. 두 버튼의 최소 높이는 44px, 좌우 패딩 12px·상하 패딩 8px, 버튼 간격 8px로 통일한다. 취소·바깥 탭은 일정과 선택 상태를 유지한다.
- 복사 완료 안내는 표준 Dialog의 제목·본문·하단 확인 버튼을 사용한다. X는 숨기고 본문·바깥 영역 또는 확인 버튼을 누르면 닫는다. 확인 버튼은 우측 정렬, 최소 높이 44px, 좌우 12px·상하 8px 패딩을 사용한다.
- 설정 항목과 동작은 좌측 정렬하며, 데이터 복원 제목 옆의 ?에서 백업 방법을 연다. 앱 이름·버전 옆의 라이선스 정보에서 글꼴과 공휴일 데이터 정보를 확인한다.
- 오늘 이동 버튼은 10px 모서리와 텍스트만 사용하고 그림자를 두지 않는다. 이동 가능한 범위 안에서 오늘 행을 가운데로 맞춘다.
- 플래너 최대 너비 960px, 설정 800px를 기준으로 태블릿에서 과도하게 늘어나지 않게 한다. 기기 회전을 지원한다.

## 입력과 칩

- 첫 화면은 월간 일정이다. 안내 문구는 “일정을 입력하세요. 쉼표(,)나 엔터로 나눌 수 있어요.”다.
- 쉼표나 엔터로 칩을 나누며 마침표는 일반 문자다. 엔터와 붙여넣은 줄바꿈(LF·CRLF·CR)은 쉼표와 동일하게 처리한다. 앞에 “13시 10분 회의” 또는 “13:10 회의”를 쓰면 시간과 내용을 분리해 저장한다. 12/24시간 설정은 표시만 바꾼다. 편집 중에는 시간을 HH:mm 텍스트로 넣어 백스페이스로 수정·삭제할 수 있다. 시간을 지우면 해당 알람도 해제한다.
- 한 입력창을 유지한다. 칩을 누르면 편집하고 앞뒤 가장자리를 누르면 해당 경계로 커서를 옮긴다. 백스페이스는 앞 칩을 편집·병합하며 중복 항목을 만들지 않는다.
- 중요 일정 별은 칩 좌측 위에 10px로 배치하며 연한 하늘색 배경을 유지한다.
- 길게 누른 뒤 놓으면 선택한다. 움직이면 같은 날짜 안에서 순서를 바꾸며 손을 놓을 때 한 번 저장한다. 여러 날짜로 드래그 이동하지 않는다.
- 선택 개수가 0이 되거나 칩 바깥의 빈 공간·날짜를 누르면 선택 모드를 종료한다. 칩 탭은 선택 전환, 작업 버튼은 해당 명령을 수행한다. 복사할 날짜 선택은 월 이동 중에도 유지한다.
- 단일·복수 선택 모두 시간·알람 설정·중요·삭제를 지원한다. 기존 시간·알람 유무와 서로 다른 시간 선택 여부로 설정 버튼을 막지 않는다. 기존 값이 있으면 모달에서 덮어쓰기 안내와 “덮어쓰기” 버튼으로 확인받는다. 시간 설정은 선택한 일정의 시간을 변경하고, 알람 설정은 선택한 모든 일정의 시간과 알람을 지정한 알람 시간으로 함께 변경한다. 일정 복사는 하나만 선택했을 때 가능하다. 여러 개 선택하면 복사 버튼을 비활성 표시하고, 누르면 “일정 복사는 하나만 가능해요.” 토스트를 띄운다. 선택한 일정 하나는 현재 화면에서 여러 날짜로 복사할 수 있다. 월·연도를 넘겨도 선택을 유지하고 복사한 칩은 해당 날짜의 기존 칩 뒤에 추가한다. 내용과 시간이 같은 일정(반복 일정 포함)이 이미 있는 날짜는 선택할 수 없으며 토스트로 안내한다. 중요 표시·알람 여부는 중복 기준에 포함하지 않는다.
- 키보드에 가려진 만큼만 스크롤하고 입력 바깥 탭·본문 드래그로 키보드를 내린다. 입력 높이는 텍스트 줄 측정을 기준으로 정한다.
- 이름이 있는 날짜에는 점을 표시하고 날짜를 누르면 안내 모달을 연다. 현재는 공휴일·보정 이름을 사용한다.

## 가이드·아이콘

가이드는 X로 닫으며 “다시 보지 않음”을 선택한 경우에만 자동 표시를 끈다. 쉼표 예시는 한 줄로 보여주고 좁은 화면에서 가로 스크롤한다. 헤더의 Feather help-circle로 다시 연다.

앱 아이콘은 assets/icon-dragon.png, Android 전경·시작 화면 마크는 assets/mark-dragon.png를 공용한다. 안경 쓴 청룡·연필·메모장을 #1F6EAC 단색 선으로 단순화한다. 그라데이션·입체 음영 없이 여백을 유지한다. 글꼴 라이선스는 assets/fonts에 보관하고 설정에서 연다.

코드 계층과 스타일 분리 규칙은 [3계층 컨벤션](3tier-code-convention.md)을 따른다.

중요 일정은 별표와 theme.selected 배경으로 구분한다. 드래그 삽입 위치는 3px theme.accent 세로선으로 표시하며, 이동 중 React 상태 대신 Animated 값만 갱신한다. 일정 길이는 칩별 Unicode 코드 포인트 255자이며 초과 입력은 토스트로 안내한다.

플랫폼: Android adjustResize·iOS KeyboardAvoidingView를 사용한다. 태블릿·회전을 지원하며 입력·키보드·공유의 실제 기기 검증은 별도로 수행한다. 글꼴 라이선스는 assets/fonts/OFL.txt·NOTICE.json과 앱 설정에 보관한다.
